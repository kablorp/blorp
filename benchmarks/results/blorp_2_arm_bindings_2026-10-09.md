# Blorp 2 match-arm bindings — 2026-10-09

## Scope and architecture

Block-bodied tail-match arms now compose the existing binding, reassignment,
call, purity and union rules. The primary fixture
[`match/binding_original.brp`](../../blorp_2/test/e2e/fixtures/match/binding_original.brp)
passes `Number(7)`, saves an alias of the payload, reassigns the current value
through `identity(42)`, and returns the saved 7. Companions return 42 and 0
and preserve an enclosing value across arm-local shadowing.

Parsed arms publish binding syntax; checked arms publish ordered assignments.
A block's first local ordinal explicitly distinguishes its declarations from
enclosing bindings. Captures precede that boundary, so explicit `var` may
shadow captures and outer locals while same-block duplicates fail. Ordinary
assignment retains nearest-binding semantics. All arm initializers participate
in purity and cycle checking.

Lowering reuses its existing function-owned value allocator and branch-local
value block. Each arm starts from the enclosing binding map, lowers its
capture, assignments and result, and shares only identity allocation with its
siblings. Production emission is unchanged. No managed values, ARC operations,
ownership analysis, joins, loops or nested matches were introduced.

## Limits and next work

Current target values remain unmanaged. These tests establish binding scopes,
ordered values, alias preservation and branch-local computation; they do not
establish target ARC or destructor safety. Exact intermediate values and call
order are phase assertions; native outcomes alone cannot observe every
discarded call in this subset.

The agreed next order is value identity versus ownership obligations, borrow
dependencies, then independent verification, integrated through small executable
examples with granular phase tests. The [memory plan](../../blorp_2/MEMORY_PLAN.md)
records that order and forbids unchecked managed emission or speculative
frameworks. Each future managed increment must exercise mortal storage and its
runtime destruction contract.
