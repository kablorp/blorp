The candidate keeps split-C collection/binning unchanged. It returns a small profile/layout context from common collection, puts an empty canonical function list in single-unit sections, and calls the existing `emit_function` in declaration order directly inside `render_single_translation_unit`. The profile cursor, cancellation plan lookup, linkage, and compact setting follow the previous loop. The accumulator remains local from header through function bodies.
