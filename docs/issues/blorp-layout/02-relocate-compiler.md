# Relocate the Compiler Under Blorp

**Status:** Complete

## Goal

Move compiler production code to `blorp/src/compiler/` and compiler-focused
tests to `blorp/test/compiler/`. Preserve
`blorp/src/compiler/pipeline.brp` as the sole whole-compiler orchestration root.

## Scope

- Move the numbered compiler stages and compiler-owned top-level modules from
  `compiler/src/` to `blorp/src/compiler/`.
- Move `compiler/tests/` into a mirrored `blorp/test/compiler/` hierarchy.
- Move public parser, inference, typecheck, and codegen fixtures from
  `tests/test_compiler/` into registered stage or pipeline fixture directories
  below `blorp/test/compiler/`. Command-tool fixtures remain for their command
  extraction issues.
- Move root `tests/test_compiler_*` benchmark, replay, worker, and check tools,
  plus compiler dead-code, Perceus-ledger, and ownership-inventory tests, into
  named compiler test or benchmark-support directories.
- Normalize moved test basenames from `test_compiler_<area>_<name>.brp` to
  `test_<name>.brp` where the containing directories carry the lost context.
- Update imports, compiler-test ownership metadata, benchmark imports, build
  manifests, focused-check selection, and active documentation.
- Inventory `compiler/lib`, `compiler/tools`, `compiler/benchmarks`, and
  `compiler/testdata` for their final destinations. Move an asset in this issue
  only when its ownership is unambiguous and all consumers move with it.

Before renaming tests, produce a destination inventory keyed by current path,
new owner directory, new basename, and ownership-manifest identifier. Reject
collisions before any move; do not rely on the basename alone as identity.

The former stage-11 formatter and stage-12 CLI/LSP namespaces move temporarily
with the compiler source because the bootstrap compiler requires one coherent
tree. Mark them as legacy owners in `blorp/source_ownership.json`: Issues 4-10
must remove them, and Issue 11 rejects any survivor. Their temporary physical
location does not make their models compiler-owned or permit new compiler
imports of those modules.

## Required Invariants

- Pipeline phase order and stage names do not change.
- Generated Core snapshots and C remain equivalent.
- No new or unregistered compiler import enters a command implementation
  directory. The exact pre-existing inbound edges are temporary compatibility
  exceptions recorded in `COMPATIBILITY_FOLLOW_UPS.md` and mechanically
  rejected when missing or stale.
- No tests or fixtures are placed below `blorp/src/compiler/`.
- There is no compatibility copy of compiler production source in both trees.

## Non-goals

- Do not split command code out of the former stage-12 directories yet.
- Do not redesign compiler data models or optimize compiler algorithms.
- Do not force ambiguous native/build assets into `lib/`.

## Validation

Run compiler-focused checks, compiler Blorp suites, Core sanitizer coverage,
codegen audit, and a full compiler self-check. Compare pipeline dumps and warmed
self-check latency with the pre-move revision.

## Implementation Evidence

- A collision-checked inventory covered all 220 suites that were manifest-owned
  before their move and basename normalization; it reported zero destination
  collisions. A post-move executable-suite inventory found one pre-existing
  unregistered UFCS benchmark suite, registered it as suite 221, and now makes
  manifest validation reject any unregistered non-fixture `TestSuite`.
- `make` builds the canonical `blorp/src/main.brp` root against
  `blorp/src/compiler/`. The temporary relocation and standard-library
  identity bootstrap bridges were retired after their corresponding immutable
  compiler releases were pinned, as recorded in `COMPATIBILITY_FOLLOW_UPS.md`.

- Core ASan/UBSan gate: 1,709 passed, 0 failed.
- Production direct-check fixtures: 54 passed, 0 failed.
- Generated-C warning audit: 212 passed, 0 failed.
- Representative focused coverage additionally passed the relocated CLI,
  formatter, backend bridge, Core Perceus, and UFCS benchmark suites.

  `31d61463d4be20d026e7fa26508206c085cff548c6576fa28a86ab8fcf588281`.
